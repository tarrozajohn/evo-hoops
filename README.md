# Evo Hoops

A creature basketball franchise game. Play it in your browser (works on iPhone in Safari):

**https://tarrozajohn.github.io/evo-hoops/**

- Each phone or browser keeps its own save. Settings → Show backup code moves a league between devices.
- On iPhone, tap Share → Add to Home Screen. It then opens full screen like an app, with its own icon, and works offline.

Files: `index.html` is the whole game. `manifest.webmanifest` and the icons make it installable; `sw.js` keeps a copy on the device so it opens instantly and offline.
